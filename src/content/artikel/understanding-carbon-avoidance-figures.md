Most solar proposals and sustainability reports include a line like "X tonnes of CO2e avoided per year". The number is useful, but only if you know how it was built.

## The basic formula

**Carbon avoided (tCO2e) = Solar energy generated (MWh) × Grid emission factor (tCO2e/MWh)**

The idea is simple: every MWh your solar system produces is a MWh you did not draw from the grid, so you avoid the emissions the grid would have produced for it.

## Three assumptions to check

1. **Which emission factor was used.** Grid emission factors differ by region and are revised over time. Use the latest official figure for the grid you are connected to, and state the source and year.
2. **Measured or estimated generation.** A proposal uses simulated yield; an annual report should use metered generation.
3. **Degradation over time.** Module output falls slightly each year, so long-term avoidance figures should account for it.

## Translating into "trees planted"

Some reports convert tCO2e into an equivalent number of trees. It makes the figure easier to picture, but the conversion factor varies a lot between sources, so treat it as illustrative and keep the tCO2e number as the main figure.
